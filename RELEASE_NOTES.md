# Release notes

The release workflow takes the section for the version it builds: its "- " lines go in the
GitHub release and the update feed, and the first three show in Pane's update surface. Keep
them short, one change per line. Add a `## X.Y.Z` section before tagging `vX.Y.Z`.

## 1.0.0

- Your Android emulator in a clean window, inside a device frame.
- Click, scroll and type on the screen. The frame's power and volume buttons work.
- Inspect layout, measure and pick colours, in dp.
- Drop an app on the screen to install it. Share the clipboard.
- Screenshots and recordings, with the device frame if you want it.
- Every emulator can open in Pane, without its own window.
